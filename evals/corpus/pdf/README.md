# PDF golden fixtures

Synthetic, non-personal fixtures for document conversion evaluation.

- `native-text.pdf` contains an ordinary PDF text layer. A correct baseline conversion should recover the visible sentences.

Expected visible facts are intentionally simple and stable:

1. Durable knowledge is stored as Markdown and versioned in Git.
2. The exact source reference is retained as provenance.

The fixture establishes a reproducible input for the currently supported PDF conversion path.
